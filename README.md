# Concurrente-2026C1
Material completo de la materia Programación Concurrente. 1er cuatrimestre 2026. Cátedra Deymonnaz.

### Contenido

- `concu-apuntes`: apuntes en formato Markdown de las clases dictadas durante el cuatrimestre (ordenadas cronológicamente).
    - El archivo `repaso_parcial` contiene un repaso sintético de los temas anteriores al parcial de la materia.
    - El archivo `repaso_final` contiene preguntas del estilo que toman en las fechas de final (se incluyen todos los temas de la cursada).
- `practica`: ejercicios tomados del repositorio de ejemplos, pero aquí con **comentarios explicativos** de cada parte importante de las resoluciones que se ven en la práctica.
- `tp`: resolución del TP grupal del Sistema de Bicicletas de la Ciudad.
